# نجّار — حاسبة الورشة

أبلكيشن للنجارة بيشتغل على الموبايل والكمبيوتر، ومن غير نت بعد أول مرة.

## بيعمل إيه

- **الشغلانة:** جزامة قلابة، دولاب بضلف (على جنب أو لفوق بالبيستون)، وحدة أدراج بالمجاري، مكتبة رفوف، شغل حر، أو **شغلانة جديدة تعملها بنفسك** وتتحفظ. بتكتب المقاسات فيطلعلك:
  - هل الضلف هتقفل كويس ولا لأ
  - أماكن الخرم على الجنب والضلفة
  - رسمة 3D تقدر تلفها وتفتح الضلف فيها
  - كل القطع المطلوبة
- **التقطيع:** بتختار مقاس اللوح، فيرسملك كل لوح وإزاي تقطعه، وكام لوح هتحتاج، ونسبة الهدر. وتقدر تبعت قايمة التقطيع لمحل التقطيع على واتساب أو تطبعها.
- **الحساب:** بتكتب الأسعار، فيطلعلك التكلفة وسعر البيع والمكسب.
- **المفصلات والخشب:** مكتبة أنواع المفصلات (قلابة، سوستة طابق ونص طابق وداخلي، عادية، بيستون) والمجاري، بمقاساتها وأسعارها. تقدر تعدّل عليها وتضيف أنواع جديدة.

## تنزيله على الموبايل

- **أندرويد (كروم):** افتح اللينك ودوس «نزّل الأبلكيشن» فوق.
- **آيفون (سفاري):** زرار المشاركة ← «إضافة إلى الشاشة الرئيسية».

## تشغيله على الكمبيوتر

```bash
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

## الملفات

```
index.html            الصفحة
css/style.css         التصميم
js/app.js             الحسابات والرسومات
js/packer.js          خطة تقطيع الألواح
sw.js                 تشغيله من غير نت
manifest.webmanifest  تنزيله كأبلكيشن
icons/                الأيقونات
```

كل المقاسات بالسنتي. البيانات بتتحفظ على الجهاز نفسه بس.
